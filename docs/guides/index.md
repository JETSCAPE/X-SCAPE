# User Guide

Practical instructions for building and running X-SCAPE.

<div class="grid cards" markdown>

- **[Installation](installation.md)** — prerequisites, fetching external
  packages, CMake options, and build recipes (CPU, GPU, Docker).

- **[Running X-SCAPE](running.md)** — the executables, the two-file XML
  configuration, output, and parallel runs.

- **[Published Tunes](tunes.md)** — the JETSCAPE Default-tunes repository: how
  to run a published parameter set and how to cite it.

- **[Examples](examples.md)** — a guided tour of the bundled example programs.

</div>

!!! note "Authoritative install instructions"
    The single source of truth for installation is
    [`INSTALL.md`](https://github.com/JETSCAPE/X-SCAPE/blob/main/INSTALL.md) in
    the repository root and the
    [project wiki](https://github.com/JETSCAPE/X-SCAPE/wiki/Doc.Installation).
    The [Installation](installation.md) page here summarizes them; if the two
    disagree, trust `INSTALL.md`.
